# مورد v0.1.0

## الإضافات
- الخادم الكامل (المستخدمون والأدوار، المحلات، الكتالوج والصور المفرّغة، الطلبات وSLA، التوصيل، المالية والدفتر، العروض، التقارير، الدعم، النسخ الاحتياطي المشفّر).
- تطبيق الويب PWA: واجهة المحل، لوحة الإدارة الشاملة، واجهة المندوب.
- تطبيق Android الأساسي: دخول موحد وتوجيه بالدور، الكتالوج بلا نت، مسودة السلة على الجهاز، لوحة المؤشرات، مهام المندوب، شاشة #test، التحديث التلقائي.

## المميزات
- كل كتابة عبر الخادم بصلاحيات وتدقيق ومنع تكرار؛ المال بالأغورة بلا كسور عشرية.
- هوية «M بالنقطة» ورموز تصميم OKLCH موحّدة بين الويب وAndroid مع اختبار تباين.

## الإصلاحات
- السماح بـ PUT في CORS لمسارات الوحدات والأدوار.
